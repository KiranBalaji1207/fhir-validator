FHIR Validator

A free, static, client-side FHIR resource validator — hosted on GitHub Pages

View on GitHub ↗

1. Provide a FHIR resource

Offline checks run entirely in your browser and include real validation against the official FHIR base JSON Schema (once you add it to this repo — see README) using a locally-bundled copy of the Ajv engine — no third-party network calls at all. Nothing ever leaves your browser except same-origin requests to your own GitHub Pages site. Online check sends the resource to the public HL7 validator service (validator.fhir.org) for full profile, terminology and invariant validation; it requires internet access and may be blocked on restrictive corporate networks, in which case a one-click fallback to the official site is provided.

2. Results

👋 Paste or upload a FHIR resource, then click one of the validate buttons.

Nothing is sent anywhere unless you click "Send to official HL7 validator".

Built as a static site — safe to host on GitHub Pages. No backend, no server-side code, no data stored. Offline checks use the official FHIR JSON Schema (self-hosted, see README); online checks call the public validator.fhir.org service maintained by the FHIR community / HL7.
