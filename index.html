This site never calls an external API - everything above runs in your browser, and checks structure only (shape, required fields, cardinality, data types). Terminology bindings, invariants (like ref-2, cpt-2), and other deeper rules need the official HL7 validator, which is a Java program - it can't run inside a browser or a static site, so it has to run on your own machine.

  1. Download validator_cli.jar (requires Java 11+)
  2. as fhir-resource.json
  3. Run this in the same folder:
    java -jar validator_cli.jar fhir-resource.json -version 4.0.1

Structural checks only: resource shape, required fields, cardinality, and primitive data types — no terminology or profile lookups, and no network calls.

Checks structure (shape, required fields, cardinality, data types) against a curated FHIR R4 schema built into this page. It does not check terminology bindings, custom profiles/extensions beyond the base spec, or invariants — for that, cross-check against the official FHIR R4 specification.
